# India Smartphone & Social Media Analytics (2015–2025)

## Project Overview

This project analyzes India's smartphone, internet, and social media trends between **2015 and 2025** using Microsoft Excel.

The dashboard was built using **Power Query, Pivot Tables, Pivot Charts, KPIs, Excel formulas, and Slicers** to transform research-based data into interactive business insights.

## Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Slicers

## Key Insights

* Internet users reached **806 million**.
* Social media users reached **491 million**.
* Android holds **95%** market share.
* Average daily social media usage reached **3.2 hours**.
